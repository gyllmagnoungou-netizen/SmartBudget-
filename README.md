#  SmartBudget

SmartBudget est une application web de gestion financière personnelle développée avec Python, Flask et SQLite.

Elle permet aux utilisateurs de suivre leurs revenus et dépenses, de visualiser leur situation financière et de gérer leur budget quotidien à travers une interface moderne et intuitive.

---

##  Fonctionnalités

- Ajout de revenus
- Ajout de dépenses
- Calcul automatique du solde
- Historique des opérations
- Suppression des revenus et dépenses
- Base de données SQLite
- Tableau de bord financier
- Graphique Revenus vs Dépenses
- Interface moderne noir & or

---

## ⚙️ Installation

Cloner le projet :

```bash
git clone https://github.com/VOTRE_PSEUDO/SmartBudgetAI.git
```

Accéder au dossier :

```bash
cd SmartBudgetAI
```

Créer un environnement virtuel :

```bash
python -m venv venv
```

Activer l'environnement virtuel :

```bash
venv\Scripts\activate
```

Installer les dépendances :

```bash
pip install -r requirements.txt
```

Lancer l'application :

```bash
python app.py
```

Ouvrir ensuite :

```text
http://127.0.0.1:5000
```
